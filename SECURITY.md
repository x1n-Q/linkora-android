# Security Policy

## Supported versions

Security fixes are applied to the latest published Linkora Mobile release. Users
should update to the newest available version before reporting behavior that may
already be fixed.

| Version | Supported |
| --- | --- |
| 0.7.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected app and Runtime Pack versions;
- the Android version and device architecture;
- steps required to reproduce the issue;
- the security impact;
- logs or proof-of-concept files with secrets removed; and
- any suggested mitigation.

Allow time to reproduce and fix the issue before publishing details. Reports
about abuse of a Linkora hostname should use the
[Linkora abuse report](https://linkora.top/report-abuse) instead.
