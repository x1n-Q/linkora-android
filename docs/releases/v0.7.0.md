## Linkora Mobile 0.7.0

Linkora Mobile runs and publishes supported web projects directly from an
Android phone. A Linkora account is optional; standalone projects can remain on
the device, be shared on a trusted local network, or use a user-managed domain.

### Included

- Real project folders selected through Android Files
- Built-in static-site hosting
- Optional Runtime Packs for Node.js, PHP, MariaDB, and Linkora Connector
- Project controls, logs, uptime, and memory information
- Background operation through an Android foreground service
- Browser-based Linkora authorization without sharing the account password
- Standalone publishing without a Linkora account

### Install

Download `linkora-mobile-v0.7.0.apk` below and open it on an Android 8.0 or
later device.

Current Node.js, PHP, MariaDB, and connector Runtime Packs support 64-bit ARM
devices (`arm64-v8a`). Static hosting in the main application is
architecture-neutral.
